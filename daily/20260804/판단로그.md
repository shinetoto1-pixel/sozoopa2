# 2단계 판단로그 — 20260804

## 클러스터 병합 메모

`클러스터후보.md`는 키워드별 기계적 묶음이라 같은 사건이 여러 키워드로 쪼개져 있었다. 아래처럼 의미
단위로 병합해서 봤다(주요 사례만):
- 폭염 + 온열질환 + 중대본 + 역대최고기온 + 기능성세제 → 폭염 하나
- ESS + LFP배터리 + 호남 + ESS배터리 + LG엔솔 + LFP양극재 + 탈중국밸류체인 → ESS/2차전지 하나
- 전력기기 + 수주잔고 + AIDC전력 + 전력병목 + AI메모리(전력설비 부분) + 전력설비 → 전력설비 하나
- HBM + 빅테크AI투자 + 메모리반도체 + 설비투자 + 3D메모리 + AI반도체(일부) + 메모리칩 + 장기계약 +
  하이닉스 + 미국공장 + 구독형AI인프라 → HBM/메모리반도체 하나
- 해상데이터센터 + 조선업 + K엔진 + AIDC전력(엔진쪽) + 한화 + 방산(조선 부분) → 조선 하나

세제개편 관련 키워드(세제지원·세제개편·국내생산촉진세제·저PBR·중복상장·개소세·코인과세·석화구조조정 등)는
하나의 큰 정책 발표(8·3 세제개편안) 파생인데, 업종별로 호재/우려가 혼재하고(반도체·AI로봇엔 호재, 친환경차
개소세 감면 종료는 우려) 방향성이 뚜렷한 매매 테마로 묶기 어려워 테마 후보에서 제외하고 배경 정책 뉴스로만
취급했다.

## 선정 테마 (5개)

### 1. 폭염
- **금액 규모**: 전남·광주에서만 축산 3만마리 폐사(피해액 4.43억), 수산 넙치 7.5만마리 폐사(6.01억),
  벼 잎도열병 2,368ha 발생. 전국 단위로는 훨씬 큼.
- **클러스터링 강도**: 7건, 여러 지역(인천·전북·경남·전남광주)·여러 각도(사망·중대본 격상·기록경신·
  소비패턴 변화)에서 교차 확인됨.
- **신규성**: 경남 양산 41.6도 역대 최고기온 재차 경신, 행안부 폭염 중대본 2단계 격상(정부 공식 대응
  강화), 첫 온열질환 사망 발생 — 전형적 "매년 반복되는 여름 뉴스"가 아니라 오늘 이례적 지점(기록 경신·
  단계 격상)이 있어 [[테마패턴매핑]]의 기각 기준(카테고리 반복성만으로는 기각 안 함, 이례적 수치·사건
  여부로 판단)을 통과.
- 경제이슈참고의 "채소값 30%↑" 기사도 같은 방향을 뒷받침.

### 2. 전력설비
- **금액 규모**: 전력기기 3사(효성중공업·HD현대일렉트릭·LS ELECTRIC) 2분기 합산 영업이익 7,298억원,
  누적 수주잔고 36조 7,254억원. 개별로도 효성중공업 17.5조(+63%), HD현대일렉트릭 12.2조(+29.6%),
  LS ELECTRIC 7조(+81.5%) — 세 회사 모두 전년 대비 두 자릿수~수십% 증가.
- **클러스터링 강도**: 전력기기 3사 실적 기사 + AIDC 전력평가 10GW 병목 기사가 서로 다른 각도에서
  "AI데이터센터發 전력수요 급증"을 교차 확인.
- **신규성**: 노후 전력망 교체 수요와 AI데이터센터 신규 수요가 겹치는 구조적 변곡점 — 2030년까지 매년
  10%↑ 전망은 배경이지만, 오늘 나온 2분기 실적치·수주잔고 자체가 이례적 규모.
- **주의**: `테마패턴매핑.md`의 "큰 클러스터가 시장 편향일 수 있다" 경고를 감안해 클러스터 크기가 아니라
  실적·수주 수치 자체의 이례성으로 판단했다.

### 3. HBM/메모리반도체
- **금액 규모**: 삼성전자 반도체+SK하이닉스 2분기 영업이익 합산 150조원(삼성 89.2조, SK하이닉스 60.5조).
- **클러스터링 강도**: 7건 — 실적(150조), 5년 장기계약 구조("구독형 AI 인프라"), 메모리 초호황 2030년까지
  전망, 하이닉스 인디애나 공장 착공식, 3D메모리 등 서로 다른 각도.
- **신규성**: "가격 급등락하던 부품"에서 "5년치 선수금 받는 구독형 인프라"로 계약 구조 자체가 바뀐 점이
  신규 사건성 있음.
- **리스크(참고, 선정 기준엔 미반영)**: SK하이닉스 "맹탕 콘콜" 기사([17])는 시장 실망 반응이 있었다는
  신호라 3단계 작성 시 균형 잡힌 톤이 필요.
- **주의**: AI·반도체는 원래 기사量이 많은 섹션이라(`원칙.md` 3축평가 경고) 클러스터 크기가 아니라
  150조 실적·계약구조 변화라는 구체적 수치·신규성으로 선정했다.

### 4. ESS/2차전지
- **금액 규모**: 상반기 글로벌 ESS 배터리 출하량 461.3GWh(+71%), LG에너지솔루션 12.0GWh(+357%).
- **클러스터링 강도**: 4건 — 글로벌 출하량 통계, 배터리 3사 호남 ESS 공략, 엘엔에프 국내 첫 LFP 양극재
  출하가 서로 다른 기업·각도에서 교차.
- **신규성**: 엘엔에프의 "국내 첫 LFP 양극재 시생산 출하"는 탈중국 밸류체인 구축의 신규 이정표.
- **주의**: LG엔솔 357% 성장은 기저효과(점유율 2.6%로 절대 규모는 작음)라 과장 해석 주의 — 판단로그에
  기록해 3단계에서 수치를 다룰 때 참고.

### 5. 조선
- **금액 규모**: 기사 자체에 수주 규모 수치는 공개 안 됨(신규 사업의 초기 단계 — 인증·MOU 위주).
- **클러스터링 강도**: 3건 — 해상데이터센터(삼성重·HD현대 경쟁 구도), 한화 3형제 경영 체제 개편(방산·조선
  성장축), K엔진의 AIDC 전력원 신사업 확장이 "조선업의 사업 다각화"로 교차.
- **신규성**: 해상 데이터센터(FDC)는 완전히 새로운 소재 — 삼성重 50㎿급 개념설계 인증 획득, 슈퍼마이크로와
  공동개발 계약 등 구체적 진전이 있었음.
- 3축 중 금액 규모는 약하지만 신규성·교차검증이 뚜렷해 5번째로 선정. 구체적 수주 규모가 없다는 점은
  3단계 작성 시 톤 조절 필요(과장 금지).

  클러스터링 강도도 약함.
- **로봇**([7]AI로봇 세제혜택, [59]AI메가프로젝트 로봇투자, [32]진공로봇, [65]대구 로봇예산 축소): 대구
  로봇 예산이 오히려 축소(38억→12억)됐다는 반대 신호가 섞여 있어 방향성 불명확.
- **딥시크/AI 저가경쟁**([42]): 중국 기업 단독 이슈라 국내 종목과의 연결고리가 약함.
- **삼성 스마트글래스**([45]/[69], 동일기사 중복): "애플 안경 전격 등장 예고"로 아직 예고 단계이고
  삼성전자는 이미 HBM/메모리 테마에 대표종목으로 들어가 있어 중복. 개별주 이슈로 넣기엔 삼성전자가
  너무 대형주라 개별주 이슈 취지(중소형 발굴)와 안 맞음.
- **토스 페이스페이**([22]): 토스(비바리퍼블리카)가 비상장이라 직접 매매 가능한 종목이 없어 개별주
  이슈에서 제외.

## 경제이슈참고 선택 근거 (3건, 2026-08-04 두 차례 재검토)

경제이슈참고 기록 대상이 경제정책·국제경제 두 섹션(29건)으로 좁혀진 만큼, 대충 눈에 띄는 것부터
고르지 않고 29건 전체 내용을 제대로 읽고 골랐다. 1차 재검토에서 "채소값 30%↑" 기사를 넣었으나,
폭염→물가상승이라는 뻔한 관찰뿐인 낮은 밀도의 생활물가 기사라 품질 기준에 못 미쳐 제외했고, 국제경제
후보 10건을 검토하고도 최종 3건에 하나도 안 넣었던 것도 놓친 부분이라 다시 균형을 맞췄다(경제정책
2건 + 국제경제 1건, 주제도 지수/수급·국제환율공조·레버리지ETF구조로 겹치지 않게 분산).

- **외국인 매도하자 다시 급락한 코스피‥'지배구조 개선'은 계속**(경제정책): 오늘 지수 하락의 원인
  (외국인 매도)까지 설명하는 기사라, 결과만 전하는 기사보다 배경정보 가치가 높다.
- **미·일 환율공조 왜 나왔나…"우정으로 포장한 철저한 이해타산"**(국제경제): 엔화 방어 이슈의 국제적
  배경을 분석적으로 다뤄, 단순 사실 나열보다 밀도가 높다.
- **레버리지 쇼크 뒤엔 외국인 '0.001초단타'… 개미만 1조원 털렸다**(경제정책): 레버리지ETF 관련 시장
  구조 이슈를 구체적 수치(1조원)로 다룬 기사 — 어제자 "레버리지ETF 긴급조치권" 논쟁과도 이어지는
  현재진행형 이슈.
